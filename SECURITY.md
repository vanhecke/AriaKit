# Security policy

## Reporting a vulnerability

Report it privately through GitHub:
[Security → Report a vulnerability](https://github.com/vanhecke/AriaKit/security/advisories/new).
Do not open a public issue or pull request for it.

Include the AriaKit version (or commit), the platform, and steps to reproduce.

A flaw in aria2 itself (protocol parsing, TLS, BitTorrent) belongs upstream at
[aria2/aria2](https://github.com/aria2/aria2). Report it here too if AriaKit's
use of libaria2 makes it worse.

## Supported versions

Only the latest release gets fixes.
